# Discord-Bot-Starter-Bot-

This is my first bot that I have made for Discord, and only has about 12 commands.
!hi = Command for bot to say hi
!owner = tells you about the owner
!clear = clears messages
!admin = Info about Admin
!mod = Info about mod
!member = Info about member
!mute = mutes a user
!unmute = unmutes a user
!kick = kicks a user
!rules = shows rules
!giveMember = gives user member role
!takeMember = takes member role from user
